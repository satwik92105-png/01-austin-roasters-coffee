## Shared Script & Styling Architecture
- **Shared Style System (`shared/styles.css`):** Defines root CSS variables for colors (`#0d0c0a`, `#151210`, `#c9a84c`, `#e8c872`), typography (Cinzel & Inter), grid rhythm, and responsive utility classes.
- **Shared Component Engine (`shared/components.js`):** Unified header navigation, mobile drawer toggles, Cart Drawer singleton, and drink customizer logic.
- **Shared API Client (`shared/api-client.js`):** Orchestrates communication between static frontend pages and Vercel serverless backend endpoints (`/api/*`), including fallback offline mock state when disconnected.
